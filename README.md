# LibrePE
LibrePE is a better version of the original Windows PE based on Windows PE 11.
It brings more features to LibrePE than the normal PE, such as Firefox, 7-zip, Winver, Powershell and more

# Diferences of LibrePE and Windows PE
| Feature | WinPE | LibrePE |
|---|:---:|:---:|
| New wallpaper | ❌ | ✅ |
| Firefox Nightly | ❌ | ✅ |
| 7zip pre-installed | ❌ | ✅ |
| Windows Version Applet | ❌ | ✅ |
| Powershell | ❌ | ✅ |
| Community-maked | ❌ | ✅ |
| Notepad++ | ❌ | ✅ |
| File Manager (Explorer++) | ❌ | ✅ |
| Created using | Windows ADK | Windows ADK |

# LibrePE as a main OS 
Following Microsoft Website, LibrePE daily use is not recommended, and only used for deployment and recovery
